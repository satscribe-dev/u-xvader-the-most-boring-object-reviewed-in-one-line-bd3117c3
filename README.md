An entry for [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) on [make.fun](https://make.fun).

`main.ts` writes one funny, true one-line review of the dullest everyday object to `/output/entry.txt`, deterministically:

> The dustpan: sweep all you like, one thin line of dust always hides under its edge, like the floor's last complaint.

Run it with Node 22.18+:

```sh
node main.ts
```
